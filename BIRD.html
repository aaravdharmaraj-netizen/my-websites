BIRD Language Rules

BIRD Syntax Overview

1. SAY [text]
Prints text.

2. COLOR [name]
Sets text color.

3. SIZE [number]
Sets font size in pixels.

4. NEWLINE
Adds a line break.

5. BOX [text]
Draws a bordered box.

6. REPEAT [n] { ... }
Loops commands.

7. RESET
Restores default color + size.

8. BACKGROUND [color]
Changes the output panel background.

9. CENTER
Centers all following text.

10. LEFT
Left-aligns all following text.

11. RIGHT
Right-aligns all following text.

12. TITLE [text]
Prints large bold title text.

13. UNDERLINE [text]
Prints underlined text.

14. ITALIC [text]
Prints italic text.

15. BOLD [text]
Prints bold text.

16. CLEAR
Clears the output panel.

17. WAIT [milliseconds]
Pauses before running the next command.
